# Arshiya Naaz — GIS & Remote Sensing Portfolio

A responsive static portfolio built with HTML, CSS, vanilla JavaScript, and Leaflet. No build step or npm installation is required.

## Run locally in VS Code
1. Extract this folder.
2. Open the `gis-portfolio-arshiya` folder in VS Code.
3. Open `index.html` with the Live Server extension (recommended), or open it in a browser.
4. Keep internet access on for Google Fonts, remote imagery, Leaflet, and map tiles.

## Included
- Responsive navigation and dark/light contrast toggle
- Real photographic Earth and landscape image URLs
- GIS skills and illustrative project cards
- Interactive Leaflet map centred on Bengaluru with street and satellite layers
- Resume link to the Google Drive URL supplied by Arshiya
- Email, LinkedIn, GitHub Pages and phone links
- Contact form that opens a prefilled email (it does not send without the visitor's action)

## Before publishing
- Project cards are explicitly illustrative themes. Replace them with actual work, study areas, methods, outputs and findings; do not present them as completed projects unless they are.
- The resume button opens the supplied Google Drive file link. To allow visitors to view it, set Drive sharing to **Anyone with the link — Viewer**. The button opens the Drive preview rather than guaranteeing a direct file download.
- The GitHub URL supplied was `https://arshiyanaaz7798-bot.github.io/`; it is labelled GitHub Pages because it is a website URL, not a confirmed GitHub profile URL.
- Phone number is displayed as provided: +91 63645 95393.
- This is a static site. The contact form uses `mailto:` and requires the visitor to have an email application configured; use a form backend if you want messages submitted directly from the website.

## GitHub Pages deployment
1. Create or open a GitHub repository for the portfolio.
2. Upload `index.html`, `style.css`, `script.js`, and this README at the repository root.
3. Open **Settings → Pages**, select the main branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and open the URL it provides.
